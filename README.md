Thornwood Defense is a tower defence game: five tower kinds, five blight kinds, twelve waves, and one Heartwood to protect. The blight marches down a winding road through the forest; you build towers on the grass beside it, spend gold on upgrades, and hold the Heartwood through all twelve waves — the last one brings two Blight Brutes.

## How to play

- Click a tower in the bar below (or press 1–5), then click the field to build it.
- Click a tower you built to upgrade it or sell it back.
- Press Space (or the Send Wave button) to send the next wave. F fast-forwards, P pauses, M mutes, R restarts after the end.
- Towers: Thorn Spitter (fast and cheap), Frost Shard (slows), Ember Cannon (splash), Storm Coil (chain lightning), Vine Snare (holds them still).
- The blight: Mites (fast), Beetles (tough), Swifts (faster), Wisps (fastest), and the Blight Brute (boss, costs 5 lives if it gets through).
- Win by clearing wave 12. Lose if the Heartwood's 20 lives run out.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

No build step, no libraries, no network requests: plain HTML, CSS and JavaScript that runs offline in a desktop browser from its own files. Sound is synthesized live with WebAudio.
